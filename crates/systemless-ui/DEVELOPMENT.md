# egui integration acceptance criteria

Current objective: integrate egui into Systemless with a dockable guest pane and inspector, preserving the independent design-system crate. Keep all work on `dev/wgpu-ui-kit`, draft PR #4866, without merging.

The previous custom UI runtime and its component checklist are superseded. Historical test counts and gallery screenshots are not evidence for this migration. Integration takes priority over expanding the component catalogue.

- [x] Replace custom runtime with egui; preserve standalone crate boundary.
- [x] Semantic palettes, density, reduced motion, component and dock styling.
- [x] Standalone gallery compiles; validated layout persistence and theme checks pass.
- [x] Embed egui-winit in Systemless's existing event loop.
- [x] Compose guest texture and UI on the existing wgpu device; present once.
- [x] Dockable guest pane and inspector show real runtime data.
- [x] Guest input uses the visible pane rectangle; ownership lasts through release.
- [x] UI overlays, keyboard focus and host cursors do not leak input to the guest.
- [x] UI redraws independently of new guest frames, including paused/idle states.
- [x] Preserve guest color, crop, scaling and retained GPU presentation.
- [x] Resize, DPI, surface recovery and offscreen layout recovery tested.
- [x] Independent crate tests, integration tests, real GPU checks and native smoke tests pass: CI's native window qualification passes the four workspace cases (inline/threaded × CPU/wgpu guest rendering) on hosted macOS, Linux X11 (Xvfb/Openbox), Windows and Wayland (headless Weston), and the workspace GPU tests pass on Linux software Vulkan. On Wayland the compositor owns focus, fullscreen placement and pointer warps, so those steps are skipped there and pointer motion is delivered through the winit input adapter. These are scripted checks, not hands-on use. A separate CI job drives the live workspace through the platform accessibility APIs that screen readers read: AT-SPI on Linux (Orca) and UI Automation on Windows (NVDA, Narrator).
- [x] Systemless-implemented Macintosh menus (menu bar, PopUpMenuSelect and popup controls), Standard File, alerts, modal and modeless dialogs, the Color Picker, Printing Manager dialogs and Notification Manager alerts use egui, preserving 68K/PPC callbacks and modal semantics. Application-drawn items (user items, custom CDEF controls, artwork Systemless cannot decode) are embedded in the native egui dialog as live guest pixels, and dialogs with application filter procedures stay native with the filter in ModalDialog's loop. Only dialogs with custom window definitions, and modeless dialogs with application-drawn items, are framed whole around the guest's pixels.
- [x] Documentation, license gates, reviewed commits and updated draft PR; no merge.

Retain the existing guest-only presentation path while proving the workspace integration. Native platform and screen-reader results must be reported separately from headless tests.
