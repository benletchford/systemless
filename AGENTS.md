# Repository instructions

Read `README.md` before making changes.

## GitHub evidence

- Attach screenshots and other media used only by an issue or pull request to
  that GitHub conversation. Do not commit issue-only or pull-request-only
  evidence to this repository.
- Commit images only when they are consumed by project documentation, tests,
  examples, or shipped assets.
- Do not create `docs/issue-evidence/` or an equivalent repository-hosted
  discussion-attachment directory.
- Keep public issue and pull-request text scoped to the standalone Systemless
  repository and its public interfaces.

## Commit messages

Use a one-line Conventional Commit message with no body or attribution trailer.
