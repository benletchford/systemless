frames referenced by issue #377. Both captures use the public Bonkheads Deluxe
archive with SHA-256
`e0f909205dc13ea1ccf3e66c406212983f9cd1c66255b0354bf9c2b808dfe821`.

after its live control record has become invisible, while BasiliskII keeps it

evidence note's claim.
