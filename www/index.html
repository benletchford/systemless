Classic 68K and PowerPC Macintosh games in your browser

Systemless is a ROM-free classic Mac runtime for playable preservation, serving original 68K and PowerPC Macintosh game archives directly on the web.

Run your own application

On macOS, install with Homebrew: brew install benletchford/tap/systemless

On other platforms, install with Cargo: cargo install systemless

Then launch an application: systemless path/to/application.sit

The game library is loaded from the community catalogue.
