# Catalogue delivery goal

Grow systemless.org to **1,000 distinct, qualified classic Macintosh games**, prioritising well-known titles and supporting both 68K and PowerPC. Use [the target list](CATALOGUE-TARGETS-1000.md) as the intake queue and [the progress ledger](CATALOGUE-PROGRESS.md) as the evidence record.

For each item, identify the intact original distribution and applicable redistribution permission; reproduce its behaviour on each available architecture; attempt focused compatibility fixes; verify bounded gameplay and input; capture an accurate screenshot; and submit the entry through catalogue validation, asset promotion, deployment and browser launch approval. Verify the exact hosted package and released route on systemless.org before counting it as delivered. Replace candidates that cannot qualify with reserves.

Advance catalogue publication and emulator compatibility together. Keep a publication-ready candidate moving while investigating deeper defects in other games. Prefer finishing candidates with clear distribution terms and working gameplay before accumulating more unqualified intake. Record each fix, exact-package retest, remaining blocker and next action so work can continue without repeating the investigation.

Measure progress separately as qualified live games, staged catalogue records, and compatibility fixes merged. Report changes in those counts with supporting links. A new record, a title screen or a successful build is an intermediate result; the goal is complete only when 1,000 distinct qualified games are live.
