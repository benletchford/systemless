## Noto Sans Mono nine-point fallback

The unmodified `NotoSansMono-Regular.ttf` and `NotoSansMono-OFL.txt` come from
[notofonts/noto-fonts](https://github.com/notofonts/noto-fonts/tree/326a408bd3657d082c9af9ebd63e9e1bed599d10),
commit `326a408bd3657d082c9af9ebd63e9e1bed599d10`:

- font: `hinted/ttf/NotoSansMono/NotoSansMono-Regular.ttf`
- licence: the repository's `LICENSE`, retained as `NotoSansMono-OFL.txt`
- font SHA-256: `d9e2b23d19f8230be7146f409a52b1d23117e635e28f2e2892cf91b7382f325b`

This is a sans-serif screen substitute for unresolved nine-point Monaco ASCII
requests. The existing logical advances and GetFontInfo line metrics remain;
extended Mac Roman and other sizes continue using the URW substitute. Guest
fonts and explicit local overrides retain priority. No Apple font software or
artwork is included. Preserve the separate SIL OFL notice in distributions.
